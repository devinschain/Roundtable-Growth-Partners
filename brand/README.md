# RGP brand kit

- `brand-guide.html`: open in a browser for logos, colors, contrast and type
- `logos/`: SVG logos (monogram, horizontal lockup, wordmark, each with a reversed version) plus alt-* concepts not chosen
- `png/`: PNG exports with transparent backgrounds, plus favicon and apple-touch-icon
- `colors/`: `palette.json`, `colors.css` (CSS variables), and the four palette options shown earlier
- `logo-concepts.html`: the four logo concepts

Note: logo text uses Georgia as a stand-in for Fraunces; outline the type in final artwork. This folder sits inside the website folder, so it will be published with the site unless you exclude it (move it out, or add it to .gitignore).
