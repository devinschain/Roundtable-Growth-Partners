# Roundtable Growth Partners website

Static site (no build step): `index.html`, `styles.css`, `favicon.svg`, `assets/`.

## Deploy with GitHub + Cloudflare Pages
1. Push this folder to a GitHub repository.
2. In Cloudflare: Workers & Pages > Create > Pages > Connect to Git > pick the repo.
3. Framework preset: None. Build command: leave empty. Build output directory: `/` (the repo root).
4. Add your custom domain under the project's Custom domains tab.
